# University Enrollment Analysis
A data analytics portfolio project using SQL, SQLite, Python, and data visualization methods.

# Project Objectives
* Analyze unversity enrollment trends
* Calculate retention
* Compare enrollment to major
* Identify Trends in student performance

# Software Used
* Python
* SQLite
* SQL
* Pandas
* Vs Code

# Data Used
* MSU data files from IPEDS 2024 (Most Recent Available)
